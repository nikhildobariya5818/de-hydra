# Quick Start Guide - De'Hydra Admin Panel

## 🚀 Getting Started

### Step 1: Access the Admin Panel
1. Go to `https://your-domain.com/admin/login`
2. Enter your admin email and password
3. You'll be redirected to the dashboard

### Step 2: Manage Products

#### Add a New Product
1. Click **"Add Product"** from dashboard or go to Products page
2. Fill in the form:
   - **Product Name**: e.g., "Dehydrated Tomatoes"
   - **Category**: e.g., "Vegetables"
   - **Price**: e.g., 25.99
   - **Description**: Detailed product info
   - **Image URL**: Link to product image
3. Click **"Save Product"**

#### Edit a Product
1. Go to Products → Find product → Click **"Edit"**
2. Update any fields
3. Click **"Save Product"**

#### Delete a Product
1. Go to Products → Find product → Click **"Delete"**
2. Confirm deletion

### Step 3: Manage Certifications

1. Go to Admin Dashboard → **"Manage Certifications"**
2. Follow similar steps as products
3. Add certification images and validation details

### Step 4: Manage Blog Posts (Insights & Industry Knowledge)

1. Click **"Add Blog Post"** from dashboard
2. Fill in:
   - **Title**: Article title
   - **Slug**: Auto-generated from title
   - **Content**: Full article text
   - **Category**: e.g., "Food Safety", "Industry News"
   - **Featured Image**: Banner image URL
3. **Draft Mode**: Uncheck "Published" to save as draft
4. **Publish**: Check "Published" when ready to go live

### Step 5: Manage Client Reviews

1. Go to **"Client Reviews"** section
2. **Add Review**: Click **"+ Add Review"**
   - Client Name
   - Company
   - Role/Position
   - Review Text (what they said)
   - Rating (1-5 stars)
   - Profile Image URL
3. **Publish/Draft**: Toggle between "Draft" and "Published"
4. **Featured**: Mark as featured for homepage display

### Step 6: Monitor Bulk Orders

1. Go to **"Bulk Orders"** from dashboard
2. See all client requests with:
   - Client details
   - Product interest
   - Quantity requested
   - Timeline needed
3. **Update Status**: Change from "Pending" → "In Progress" → "Completed"
4. **Add Notes**: Add admin notes for internal reference
5. **Contact Client**: Email is stored for easy outreach

## 📊 Dashboard Overview

The dashboard shows:
- **Products Count**: Total products in system
- **Certifications Count**: Active certifications
- **Client Reviews**: Pending reviews to moderate
- **Bulk Orders**: Open orders needing attention

## 💡 Pro Tips

### Product Management
- Use descriptive names (include size/form)
- Add high-quality images (recommended 800x600px)
- Set sort_order to control display order
- Mark popular items as "Featured"

### Blog/Content
- Write SEO-friendly titles (50-60 chars)
- Use clear sections in content
- Add featured image for visual appeal
- Schedule future posts by keeping unpublished

### Reviews
- Moderate for quality and relevance
- Featured reviews show on homepage
- Request reviews from satisfied customers
- Showcase diverse testimonials

### Bulk Orders
- Respond within 24 hours for best conversion
- Keep detailed notes on negotiations
- Track all communication
- Follow up on "in progress" orders

## 🚨 Common Tasks

### Update Product Price
1. Go to Products
2. Click Edit on product
3. Change Price field
4. Save

### Publish a Draft Article
1. Go to Blog Posts
2. Click Edit
3. Check "Published" checkbox
4. Save

### Change Bulk Order Status
1. Go to Bulk Orders
2. Click status dropdown
3. Select new status
4. Auto-saves

### Feature a Product
1. Go to Products → Edit
2. Check "Featured Product"
3. Save (appears prominently on site)

## 📞 Getting Help

### If You Forget Your Password
- Contact your site administrator
- Password reset via email (when configured)

### If Data Isn't Showing
1. Refresh the page
2. Check if content is "Published"
3. Clear browser cache
4. Check browser console for errors

### If Adding Content Fails
- Verify image URLs are valid
- Check for required fields (marked with *)
- Ensure email format is correct
- Check browser connection

## 🔐 Security Notes

- **Change Default Password**: Do this first!
- **Logout**: Always logout on shared computers
- **Don't Share Login**: Each person needs their own account
- **Image URLs**: Use HTTPS URLs only
- **Content**: Don't add personal/sensitive info publicly

## 📱 Mobile Access

Admin panel works on mobile but best on desktop. You can:
- View bulk orders on phone
- Update order status
- Read reviews
- But editing is easier on desktop

## 🔄 Syncing with Website

Content updates appear on the site **instantly**:
- Add product → Shows on /products immediately
- Publish blog → Appears in /insights
- Update review → Changes on homepage
- Change order status → Admin sees update

No need to "publish" the site separately!

## ⚡ Performance Tips

1. **Optimize Images**: Keep image files < 500KB
2. **Meaningful Descriptions**: Better for SEO
3. **Regular Cleanup**: Delete unused drafts
4. **Batch Updates**: Update multiple items when possible
5. **Backup Data**: Regularly export important data
